# Checking the fixed G11 edge function

The 16 edges are the concrete list in the upstream file PEqualNP/Outside/R_meta_2258_47.lean. The two related upstream bridge lemmas R_meta_1342_642 and L_meta_8231 use precisely the same 16 positive pairs and 24 maximal independent sets as seed.py. For a monotone circuit these rows suffice: every positive assignment contains a minimal positive pair, and every negative assignment extends to a maximal negative.

The included Lean positive control is exactly 22 gates, not an answer to a request for 21. A kernel-checked bitvector theorem verifies its truth table without using a native-decide axiom; a separate Python replay evaluates all 2,048 masks. The positive control chooses a seven-vertex cover and factors stars, then ORs the terms. The graph has 22 size-seven covers and no cover of size six, verified by seed.py; this cover count is not a circuit lower bound.

Exact-top.py searches only the specified terminal-product shape, with two junk ANDs and a fixed number of terminal products at total size 21. It makes no statement about other topologies; a timeout is unknown. search.cpp starts from one-gate simplifications of cover circuits and rewires by estimated errors. No-fit is not a lower bound.

## Exact small routing bases

`exact-small-route.cpp` independently builds the 40 decisive rows from the 16 graph edges and enumerates every ordered earlier-wire basis of size 2 (ten terminal products) or 4 (nine terminal products), with exactly two junk ANDs (they are true on a maximal independent set). Gates use distinct earlier operands. We only need to consider the positive edge masks of possible terminal products. A product is eligible if all maximal independent sets are false. An eligible product with k positive edges can save at most k-1 terms versus singleton-edge products. For each circuit, the sum of k-1 over all distinct eligible multi-edge masks is an upper bound on total savings, even with overlapping terms. If the bound ever permits the target, the program falls back to exhaustive cover search. Its search deliberately allows unused routing wires and semantic duplicates; that can only enlarge the possible layouts.

Results: nine terminals (four routing gates) has 83,045,364 layouts and at most three aggregate savings in any layout, short of the required seven. Ten terminals (two routing gates) has 1,755 layouts, all with zero aggregate savings, short of six. These deterministic exclusions apply only to exactly-two-junk, terminal-product forms with these term counts, not to an arbitrary 21-gate circuit. Ten terms was also excluded by the separate Z3 model. Rebuild with `g++ -O3 -std=c++17 exact-small-route.cpp -o exact-small-route` and then run `./exact-small-route 9` and `./exact-small-route 10`.
